# 三倍采集（本地树木修正版）

基于 zfd 的创意工坊 Mod「三倍采集 / Triple Harvest」1.7.9.1（项目 ID：3494615834）制作。
原作者：zfd。本文件夹为本地修改副本，原订阅文件未修改。

## 本次修改

- 修复臃肿常青树名称：evergreensparse → evergreen_sparse，木头使用原有“木头”倍率配置。
- 加入天然大理石树 marbletree，以及种植大理石树通用名称 marbleshrub，覆盖种植后的各个生长阶段。
- 新增“大理石”和“大理石豆”独立倍率，默认跟随通用倍率。
- 在实际掉落时放大原始产量，保留树龄、概率掉落及非目标物品；没有掉落的大理石豆不会凭空生成。
- 使用目标的工作动作判定砍伐和采矿，支持没有 bufferedaction 的工作方式。
- 不再永久重写 GenerateLoot，树变成树桩后的挖掘掉落保持原样。
- 关闭“小幸运”的气球、鸟群事件及对应分批定时任务；移除固定及随机奖励中的迅捷气球、派对气球，保留其他宝藏。
- 原有采摘、挖掘和“小幸运”的收获、宝藏功能保留。“小幸运”会将本次可加倍资源提升至十倍，但独立设为一倍的资源仍为一倍。

## 启用方法

1. 退出并重新打开游戏，让游戏重新扫描本地 Mod。
2. 在世界的服务器模组列表中禁用原来的“三倍采集”。
3. 启用“三倍采集（本地树木修正版）”，按需调整“木头”“大理石”“大理石豆”的倍率。
4. 进入世界，砍一棵臃肿常青树、开采一棵天然大理石树及一棵种植大理石树，检查实际掉落。

不要同时启用原版与本地版，否则两份代码会共同处理资源。
本地版仍保留原版 all_clients_require_mod = true；联机伙伴也需要同一份本地 Mod。
新副本的配置需要重新选择，不会自动继承原订阅 Mod 的世界配置。

## 在另一台电脑安装

1. 打开本仓库，点击 Code → Download ZIP 下载。
2. 解压后，把包含 modinfo.lua、modmain.lua 和 images 的文件夹重命名为 triple_harvest_local。
3. 在 Steam 中右键《饥荒联机版》→ 管理 → 浏览本地文件，进入 mods 文件夹。
4. 把 triple_harvest_local 文件夹复制进去。最终结构应为 mods/triple_harvest_local/modinfo.lua；不要多套一层文件夹。
5. 重启游戏，在世界的服务器模组中关闭原版“三倍采集”，启用“三倍采集（本地树木修正版）”。
6. 两台电脑分别设置倍率；下载本 Mod 不会同步存档或世界配置。

## 已知问题

- “小幸运概率”界面中的“10%”选项实际仍为 5%；默认 2% 正确。
